# 题目 1160 - Date with MM

## 题目大意
我和妹子约会在M点到N点之间，我随机选一个时间点到达并等待最多T小时，妹子准时出现但不等待。求我能见到她的概率。

## 解题思路

**关键理解**：这是一个经典的**几何概率**问题。

1. **建立坐标系**：
   - 设我到达的时间为x，妹子到达的时间为y
   - x和y都在区间[M, N]内均匀分布
   - 所有可能的(x, y)组合构成一个边长为interval的正方形

2. **成功条件**：
   - 我能见到妹子的条件是：|x - y| ≤ T
   - 即我到达的时间与妹子到达的时间相差不超过T小时
   - 注意：妹子不等待，所以只有我等待她，她不会等我

3. **面积计算**：
   - 总面积 = interval²
   - 失败区域：|x - y| > T，即两个三角形区域
   - 每个三角形面积 = (interval - T)² / 2
   - 成功面积 = 总面积 - 2 × 三角形面积 = interval² - (interval - T)²

4. **概率公式**：
   - P = [interval² - (interval - T)²] / interval²
   - 化简得：P = (2·interval·T - T²) / interval²

## 算法分析
- **算法/数据结构**: 几何概率
- **时间复杂度**: O(1)
- **空间复杂度**: O(1)

## 关键点
- **边界情况处理**：
  - 如果T ≥ interval，概率为1（等待时间覆盖整个区间）
  - 如果T ≤ 0，概率为0（不等待）
- **精度控制**：输出保留3位小数
- **多组输入**：题目要求持续读取直到EOF
- **理解"她不等待"**：这意味着只有我等待她，所以条件是对称的|x-y| ≤ T

## 代码解析

```cpp
double interval = N - M;
```
计算时间区间长度。

```cpp
if (T >= interval) {
    cout << fixed << setprecision(3) << 1.000 << endl;
    continue;
}
```
边界情况：等待时间覆盖整个区间，一定能见到。

```cpp
if (T <= 0) {
    cout << fixed << setprecision(3) << 0.000 << endl;
    continue;
}
```
边界情况：不等待，见不到。

```cpp
double probability = (2 * interval * T - T * T) / (interval * interval);
```
核心公式：成功面积 / 总面积。
