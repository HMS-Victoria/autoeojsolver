# 题目 9 - Alice and A simple problem

## 题目大意
在m行n列的网格中填入1到10^9之间的数字，要求每个格子右边数字大于左边，下边数字大于上边。输出任意一种合法填法。

## 解题思路
这题其实很简单，关键是要理解题目要求的本质：
- 右边 > 左边 → 每一行从左到右递增
- 下边 > 上边 → 每一列从上到下递增

最直接的构造方法就是**按行优先顺序**填入1到m*n：
- 第一行从左到右填1,2,3,...,n
- 第二行从左到右填n+1,n+2,...,2n
- 以此类推

为什么这样可行？因为：
1. 每行从左到右数字递增 → 满足右边>左边
2. 每列从上到下数字递增（因为下一行的数字都比上一行大）→ 满足下边>上边

## 算法分析
- **算法/数据结构**: 直接构造
- **时间复杂度**: O(m×n)
- **空间复杂度**: O(m×n)（存储结果）

## 关键点
- 注意输入可能有多个测试用例（while循环读取直到EOF）
- 输出格式：每行数字之间用空格分隔，行末不要有多余空格
- 数字范围1到10^9，m和n最大100，所以最大数字是10000，远小于10^9，完全可行

## 代码解析
```cpp
while (cin >> m >> n) {
```
处理多组输入，直到文件结束。

```cpp
vector<vector<int>> grid(m, vector<int>(n));
int num = 1;
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        grid[i][j] = num++;
    }
}
```
按行优先顺序填充1到m*n。这样天然满足题目要求：同一行从左到右递增，下一行所有数字都比上一行大。

```cpp
for (int i = 0; i < m; i++) {
    for (int j = 0; j < n; j++) {
        if (j > 0) cout << " ";
        cout << grid[i][j];
    }
    cout << endl;
}
```
输出时注意格式：每行第一个数字前不加空格，其余数字前加一个空格。
