# 题目 12 - Drump Dislikes Trump Too

## 题目大意
给定一个无向图，每次操作可以翻转一个顶点的所有边（即删除所有邻接边，添加所有不存在的边）。问能否通过若干次操作，使得图变成完全图（任意两点都有边相连）。

## 解题思路
这道题的关键在于发现操作的本质和最终状态的数学条件。

**关键观察**：每次操作相当于翻转一个顶点的邻接关系。设顶点i的邻接向量为a_i（1表示有边，0表示无边），操作就是取反a_i。

**数学转化**：最终目标是所有a_i都是全1向量（除了对角线）。考虑两个顶点i和j，初始时它们的关系是a_i[j]（即边(i,j)是否存在）。经过一系列操作后，边(i,j)的状态变为：a_i[j] XOR x_i XOR x_j，其中x_i=1表示顶点i被操作过奇数次，0表示偶数次。

**推导条件**：最终所有边都存在，即对于任意i≠j，有：
a_i[j] XOR x_i XOR x_j = 1
等价于：x_i XOR x_j = 1 XOR a_i[j]

**两种情况**：
1. 如果初始图已经是完全图，那么显然可以（不需要操作）。
2. 否则，我们需要找到一组x_i满足上述方程。这实际上是一个关于x_i的方程组，可以转化为图论问题：对于每条边(i,j)，如果初始有边，则要求x_i = x_j；如果初始无边，则要求x_i ≠ x_j。

**结论**：这等价于判断初始图是否是一个二分图（或者完全图）。因为：
- 有边的顶点对要求x值相同（相当于在二分图的一侧）
- 无边的顶点对要求x值不同（相当于在二分图的不同侧）
- 如果图是二分图，我们可以将一侧顶点赋值为0，另一侧赋值为1，然后操作所有x=1的顶点即可

**特殊情况**：N≤2时总是可以，因为完全图或二分图条件自动满足。

## 算法分析
- **算法/数据结构**: 二分图判定（BFS染色法）
- **时间复杂度**: O(N + M) 每组数据
- **空间复杂度**: O(N + M)

## 关键点
- 理解操作的本质是翻转顶点的邻接向量，转化为异或方程组
- 将方程组的可解性转化为二分图判定问题
- 注意N≤2的特殊情况
- 完全图是二分图的特例（所有顶点同色），所以二分图判定已经覆盖了完全图情况
- 输入中城市编号从1开始，注意转换为0-based索引

## 代码解析

**并查集结构**：虽然代码中定义了UnionFind，但实际上并没有使用。这是冗余代码，核心逻辑在canBecomeComplete函数中。

**canBecomeComplete函数**：
1. 处理N≤2的边界情况
2. 构建邻接表
3. 使用BFS进行二分图染色：
   - 对每个未染色的顶点，将其染为0
   - 遍历其邻接顶点，染为相反颜色
   - 如果发现相邻顶点同色，则不是二分图
4. 如果是二分图，返回true
5. 如果不是二分图，检查是否已经是完全图（每个顶点度数为N-1）

**main函数**：读取多组数据，调用判断函数并输出结果。

注意：代码中的并查集是多余的，实际解题只需要二分图判定即可。
