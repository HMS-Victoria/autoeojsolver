# 题目 2 - 一元多项式乘法

## 题目大意
给定两个一元多项式（字符串形式），计算它们的乘积，并按次数从高到低输出所有非零项的系数。

## 解题思路

**为什么想到用 map？**
- 多项式乘法本质是“每一项与另一多项式的每一项相乘，合并同类项”
- 指数作为 key，系数作为 value，天然适合用 map 存储
- map 自动按键排序，方便最后从高到低输出

**核心步骤：**
1. **解析多项式字符串** → 得到 `指数→系数` 的映射
   - 难点：处理各种格式（`x`、`x^2`、`-3x`、常数项等）
   - 技巧：统一在前面加 `+` 号，方便按符号分割
2. **计算乘积** → 双重循环遍历两个 map，指数相加，系数相乘
3. **输出结果** → 从高次到低次遍历 map，跳过系数为 0 的项

**为什么这样解析字符串？**
- 多项式格式不统一，直接按 `+` 或 `-` 分割容易出错
- 先统一加符号，然后逐个读取：符号 → 系数 → x → 指数
- 注意处理缺省情况：系数缺省为 1，指数缺省为 0（常数项）或 1（只有 x）

## 算法分析
- **算法/数据结构**: 字符串解析 + map（有序哈希表）
- **时间复杂度**: O(n × m)，其中 n、m 分别为两个多项式的项数
- **空间复杂度**: O(n + m)

## 关键点
- **字符串解析是本题最大坑点**：要处理 `x`、`x^2`、`-3x`、`+5`、`-x` 等各种变体
- **系数可能为 long long**：乘积可能很大，用 int 会溢出
- **输出顺序**：从高次到低次，map 默认升序，要用 `rbegin()` 反向遍历
- **跳过零系数**：合并同类项后某些项可能抵消为 0
- **输入可能有空行**：需要 `continue` 跳过
