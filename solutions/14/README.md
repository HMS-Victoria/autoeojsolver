# 题目 14 - God and Gods

## 题目大意
给定两个只含AGCT的字符串，求它们最长的公共子串，且该子串必须是奇数长度的回文串（正回文串）。

## 解题思路

**为什么想到中心扩展+哈希？**
- 回文串问题，奇数长度，天然适合中心扩展法
- 需要判断两个字符串中对应子串是否相等，哈希可以O(1)判断
- 需要判断子串是否是回文，用原串哈希和反转串哈希对比

**解题步骤：**
1. 预处理两个字符串的正向哈希和反向哈希
2. 枚举所有可能的回文中心对（str1[i], str2[j]）
3. 对每个中心对，二分查找最大回文半径
4. 判断条件：str1的子串是回文 && str2的子串是回文 && 两个子串相等

**为什么二分？**
- 回文半径具有单调性：如果半径r可行，那么半径r-1也一定可行
- 所以可以二分最大半径

## 算法分析
- **算法/数据结构**: 中心扩展 + 字符串哈希 + 二分查找
- **时间复杂度**: O(n² log n)，其中n是字符串长度
- **空间复杂度**: O(n)，存储哈希数组

## 关键点
- **输入格式坑**：每行前面有数字和空格，需要提取真正的字符串部分
- **哈希计算**：注意pow函数要自己实现，不能用标准库的pow（浮点数）
- **反转串的索引映射**：原串位置i在反转串中的位置是n-1-i
- **边界条件**：二分时lo从0开始，hi取四个方向的最小值
- **回文判断**：正向哈希和反向哈希相等才说明是回文

// 提取字符串部分，去掉前面的数字和空格

    if (pos != string::npos) {
        return s.substr(pos+1);
    }
    return s;
};

// 检查 str1 中 [i-mid, i+mid] 是否是回文
