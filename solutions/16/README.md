# 题目 16 - Cows and Farmer John

## 题目大意
定义函数f(n)为不大于n的素数个数（n≤1时返回1），再定义F_k(n)为对n连续应用k次f函数的结果。给定k（可高达10^18）和n（≤10^6），求F_k(n)。

## 解题思路

**关键洞察：函数f(n)会迅速缩小到很小的值**

1. **理解函数性质**：f(n) = 不大于n的素数个数。对于n>1，f(n) < n（除了n=2,3时相等）。这意味着每次迭代，值要么不变要么减小。

2. **收敛速度极快**：
   - 当n=10^6时，f(n)≈78498（约8万）
   - 再迭代一次，f(78498)≈7700
   - 再迭代，f(7700)≈977
   - 继续：f(977)≈165，f(165)≈38，f(38)≈12，f(12)≈5，f(5)≈3，f(3)≈2
   - 之后f(2)=1，f(1)=1，稳定在1

3. **k很大的处理**：k高达10^18，但实际迭代次数很少（最多约10次）就会收敛到1或2。所以不需要真的迭代k次，一旦结果稳定就可以提前结束。

4. **预处理**：由于n≤10^6，可以先用筛法预处理出所有数的素数个数（前缀和），这样f(n)可以O(1)查询。

## 算法分析
- **算法/数据结构**: 素数筛法 + 前缀和 + 迭代
- **时间复杂度**: O(MAXN log log MAXN + 迭代次数) ≈ O(10^6)
- **空间复杂度**: O(MAXN)

## 关键点
- **迭代提前终止**：当结果≤2时，继续迭代不会改变结果（f(2)=1, f(1)=1），可以break
- **k可能为0**？题目说k≥1，但代码中循环从0到k-1，注意边界
- **n=1的情况**：f(1)=1，之后永远为1
- **输入处理**：多组数据直到文件结束

## 代码解析

```cpp
// 预处理部分：筛法求素数，并计算前缀和
void precompute() {
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i <= MAXN; i++) {
        if (is_prime[i]) {
            for (int j = i * 2; j <= MAXN; j += i) {
                is_prime[j] = false;
            }
        }
    }
    // 计算前缀和：prime_count[i] = 不大于i的素数个数
    int count = 0;
    for (int i = 1; i <= MAXN; i++) {
        if (is_prime[i]) count++;
        prime_count[i] = count;
    }
}
```

```cpp
// 核心迭代逻辑
long long F(long long k, long long n) {
    long long result = n;
    for (long long i = 0; i < k; i++) {
        result = f(result);  // 应用一次f
        if (result <= 2) break;  // 提前终止：后续不会再变化
    }
    return result;
}
```
