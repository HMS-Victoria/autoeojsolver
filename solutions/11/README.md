# 题目 11 - Cacey and Calphabet

## 题目大意
给定一个由小写字母组成的字符串，可以插入任意字符，问最少需要插入多少个字符，才能使得原字符串（不删除任何字符）包含"abcdefghijklmnopqrstuvwxyz"作为子序列。

## 解题思路

**关键洞察**：题目要求的是"插入字符"使字符串变成Calphabetical，而Calphabetical的定义是"删去零个或多个字符后可以得到26个字母序列"。这意味着原字符串中必须按顺序包含26个字母作为子序列，缺失的字母就需要插入。

**转化问题**：实际上就是求原字符串中，按顺序能匹配多少个目标字母序列中的字符。匹配得越多，需要插入的就越少。

**为什么用双指针**：
- 目标序列是固定的"abcdefghijklmnopqrstuvwxyz"
- 我们需要在原字符串中按顺序找这些字母
- 双指针可以同时遍历两个字符串，一个指针指向目标字母，一个指针扫描原字符串
- 当找到匹配的字母时，目标指针前进；无论是否匹配，原字符串指针都前进

**最终答案**：26 - 匹配成功的字母数

## 算法分析
- **算法/数据结构**: 双指针（贪心匹配）
- **时间复杂度**: O(n)，n为字符串长度（最大50）
- **空间复杂度**: O(1)

## 关键点
- 理解"子序列"和"子串"的区别：子序列不要求连续
- 双指针中，原字符串指针始终前进，目标指针只在匹配时前进
- 最终答案是26减去匹配数，而不是直接输出匹配数
- 输入可能有多行，需要用循环读取

## 代码解析

```cpp
string target = "abcdefghijklmnopqrstuvwxyz";
int i = 0, j = 0;
// i指向目标字母，j指向原字符串
while (i < 26 && j < s.length()) {
    if (s[j] == target[i]) {
        i++; // 匹配成功，找下一个目标字母
    }
    j++; // 无论如何都继续扫描原字符串
}
int ans = 26 - i; // 缺失的字母数 = 需要插入的字符数
```

核心逻辑很简单：用`i`记录已经匹配了多少个目标字母，`j`遍历原字符串。匹配到就`i++`，没匹配到就继续往后找。最后`26 - i`就是没匹配到的字母数量，也就是需要插入的字符数。
