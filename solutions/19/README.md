# 题目 19 - Teacher Panda and plagiarism

## 题目大意
给定两个长度为n的字符串A和B，要求从A和B中分别取出若干个互不重叠、长度至少为k的子串，按出现顺序组成序列S和T。如果S和T完全相同，则称这个序列是公共单词序列。求最长公共单词序列的长度（即最多能取出多少个这样的子串）。

## 解题思路

**核心问题转化**：这题本质上是一个带约束的LCS（最长公共子序列）变种问题。普通的LCS比较的是单个字符，而这里比较的是长度至少为k的连续子串（单词）。

**为什么想到DP**：
- 题目要求“按出现顺序”且“互不重叠”，这天然适合用动态规划
- 状态可以定义为dp[i][j]：考虑A的前i个字符和B的前j个字符，能形成的最长公共单词序列长度

**关键观察**：
1. 如果A[i]和B[j]不相等，那么dp[i][j]只能从dp[i-1][j]或dp[i][j-1]转移过来
2. 如果A[i]和B[j]相等，我们需要检查以它们结尾的最长公共子串长度lcs[i][j]
3. 当lcs[i][j] >= k时，我们可以选择这个公共子串作为一个单词，然后从dp[i-len][j-len]转移过来

**为什么需要lcs数组**：
- 直接暴力判断每个位置的最长公共子串会超时
- 用DP预处理lcs[i][j]：如果A[i]==B[j]，则lcs[i][j]=lcs[i-1][j-1]+1，否则为0
- 这样就能O(1)知道以(i,j)结尾的最长公共子串长度

**转移方程推导**：
- 不选：dp[i][j] = max(dp[i-1][j], dp[i][j-1])
- 选：对于len从k到lcs[i][j]，dp[i][j] = max(dp[i][j], dp[i-len][j-len] + 1)

## 算法分析
- **算法/数据结构**: 动态规划（二维DP + 预处理LCS）
- **时间复杂度**: O(n² × n) = O(n³)，其中n是字符串长度（n≤1000，但实际数据较小）
- **空间复杂度**: O(n²)

## 关键点
- **字符串索引从1开始**：方便处理边界，避免i-1和j-1越界
- **子串不能重叠**：选择长度为len的子串后，要跳到dp[i-len][j-len]，而不是dp[i-1][j-1]
- **长度至少为k**：不是只能取长度为k的子串，可以取更长，所以需要枚举len从k到lcs[i][j]
- **初始化**：dp[0][*]和dp[*][0]都为0，表示空串的情况

## 代码解析

```cpp
// 预处理lcs数组：以A[i]和B[j]结尾的最长公共子串长度
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        if (A[i] == B[j]) {
            lcs[i][j] = lcs[i-1][j-1] + 1;
        } else {
            lcs[i][j] = 0;
        }
    }
}
```
这里用DP思想，如果当前字符相等，就在之前的基础上加1，否则重置为0。

```cpp
// 主DP
for (int i = 1; i <= n; i++) {
    for (int j = 1; j <= n; j++) {
        dp[i][j] = max(dp[i-1][j], dp[i][j-1]);  // 不选当前字符
        
        if (lcs[i][j] >= k) {
            for (int len = k; len <= lcs[i][j]; len++) {
                dp[i][j] = max(dp[i][j], dp[i-len][j-len] + 1);
            }
        }
    }
}
```
注意：这里枚举len时，要确保i-len和j-len不越界（实际上因为len≤lcs[i][j]≤min(i,j)，所以不会越界）。
