# 题目 15 - Mr. Frog and big news

## 题目大意
给定两个长度均为N的数列a和b，可以任意排列它们（即自由配对），求所有配对(a_i + b_j)²之和的最小值。

## 解题思路

**关键洞察**：这是一个典型的“排序不等式”问题。

1. **直觉推导**：考虑两个数x和y，我们要最小化(x+y)²。由于平方函数是凸函数，我们希望大的数尽量和小的数配对，避免“大+大”的情况。

2. **严格证明**：对于任意四个数a₁ ≤ a₂, b₁ ≤ b₂，比较两种配对方式：
   - 正配：(a₁+b₁)² + (a₂+b₂)²
   - 反配：(a₁+b₂)² + (a₂+b₁)²
   
   展开相减可得：正配 - 反配 = 2(a₂-a₁)(b₂-b₁) ≥ 0
   所以反配（大配小）更优。

3. **推广到N个数**：由上述引理，最优策略是：一个数组升序排列，另一个数组降序排列，然后按顺序配对。

4. **为什么这样想**：看到“最小化平方和”且可以自由配对，立刻联想到排序不等式——这是处理这类问题的标准套路。

## 算法分析
- **算法/数据结构**: 贪心 + 排序
- **时间复杂度**: O(N log N)（排序的复杂度）
- **空间复杂度**: O(N)（存储两个数组）

## 关键点
- 排序方向：一个升序一个降序，不能两个都升序或都降序
- 数据范围：注意用long long，因为平方可能很大
- 多组数据：注意读入方式，每组数据第一行是N
- 负数处理：平方函数对负数也适用，排序不等式依然成立

## 代码解析

```cpp
// 读入N，注意多组数据
while (cin >> N) {
    vector<ll> a(N), b(N);
    // 读入两个数组
    for (int i = 0; i < N; i++) cin >> a[i];
    for (int i = 0; i < N; i++) cin >> b[i];
    
    // 核心：一个升序，一个降序
    sort(a.begin(), a.end());
    sort(b.begin(), b.end(), greater<ll>());
    
    // 按顺序配对计算平方和
    ll ans = 0;
    for (int i = 0; i < N; i++) {
        ll sum = a[i] + b[i];
        ans += sum * sum;
    }
    
    cout << ans << "\n";
}
```

**注意**：这里用`greater<ll>()`实现降序排序，也可以用`sort(b.rbegin(), b.rend())`。两种写法等价，选自己习惯的即可。
