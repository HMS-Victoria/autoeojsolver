# 题目 5 - 特殊的子集

## 题目大意
求集合{1,2,...,n}中所有不含相邻元素的子集的元素乘积的平方和。

## 解题思路

**为什么想到DP？**
- 题目要求所有满足条件的子集，且n≤100，子集数量指数级，不能枚举
- 相邻约束具有"无后效性"：当前选不选只影响下一个数能不能选
- 每个子集的贡献是乘积的平方，可以递推计算

**状态设计推导：**
1. 考虑线性DP，从左到右处理每个数
2. 对于第i个数，只有两种状态：选或不选
3. 设dp[i][0]表示处理到前i个数，且不选第i个数的所有合法子集的平方和
4. 设dp[i][1]表示处理到前i个数，且选第i个数的所有合法子集的平方和

**转移方程推导：**
- 不选i：可以从i-1的不选或选转移过来，因为不选i时i-1选不选都行
  - dp[i][0] = dp[i-1][0] + dp[i-1][1]
  
- 选i：只能从i-1的不选转移（不能相邻），且每个子集要乘以i
  - 原来子集乘积为P，新子集乘积为P*i
  - 平方变为(P*i)² = P² * i²
  - 所以dp[i][1] = dp[i-1][0] * i²

**边界条件：**
- dp[1][0] = 1（空集）
- dp[1][1] = 1（子集{1}，乘积为1，平方为1）

**最终答案：** dp[n][0] + dp[n][1]

## 算法分析
- **算法/数据结构**: 线性DP + 大数运算
- **时间复杂度**: O(n²)（大数乘法复杂度）
- **空间复杂度**: O(n)

## 关键点
- 注意平方的处理：选i时每个子集贡献要乘以i²而不是i
- n≤100时结果会很大，必须用高精度（大数）
- 空集也是合法子集，其乘积为1，平方为1
- 转移时注意dp[i][0]包含空集的情况

## 代码解析

**大数运算部分：**
- `multiply`：实现大数乘法，用数组逐位相乘再处理进位
- `add`：实现大数加法，从低位到高位逐位相加

**DP核心逻辑：**
```cpp
dp0[1] = "1";  // 空集
dp1[1] = "1";  // {1}

for (int i = 2; i <= n; i++) {
    // 不选i：两种情况之和
    dp0[i] = add(dp0[i-1], dp1[i-1]);
    
    // 选i：只能从不选i-1转移，乘以i²
    string i2 = multiply(to_string(i), to_string(i));
    dp1[i] = multiply(dp0[i-1], i2);
}
```
- dp0[i]直接累加前两种状态
- dp1[i]需要计算i²，然后与dp0[i-1]相乘
- 最终结果将dp0[n]和dp1[n]相加
