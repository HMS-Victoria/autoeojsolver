# 题目 6 - 多边形游戏

## 题目大意
一个凸n边形被对角线分割成n-2个三角形，其中一个涂黑。两人轮流沿对角线剪下一个“靠边”的三角形（至少有一条边是多边形边），剪到黑色者胜。判断先手是否有必胜策略。

## 解题思路

### 关键观察
1. **游戏本质**：每次只能剪掉“靠边”的三角形，即至少有一条边是原多边形边的三角形。剪掉后，多边形顶点数减1，剩下的图形仍然是凸多边形。

2. **转化为树形游戏**：将每个三角形看作一个节点，如果两个三角形共享一条对角线，则它们之间连边。这样形成的图是一棵树（因为凸多边形的三角剖分对应一棵二叉树）。黑色三角形是根节点。

3. **树上删叶游戏**：每次只能剪掉一个“叶子”三角形（即至少有一条边是多边形边的三角形，在树中对应叶子节点）。这就是经典的树上删叶游戏。

### 胜负判定
- 对于树上删叶游戏，先手必胜当且仅当根节点（黑色三角形）的度数不为0，即黑色三角形至少与一个其他三角形相邻。
- 等价地：黑色三角形至少有一条边是对角线（不是多边形的边），因为只有对角线才会连接另一个三角形。

### 简化判断
- 如果黑色三角形有0条边是多边形的边（即三条边都是对角线），则它被完全包围，先手无法直接剪到，必败。
- 如果黑色三角形至少有1条边是多边形的边，则先手可以直接剪掉它，必胜。

## 算法分析
- **算法/数据结构**: 简单判断
- **时间复杂度**: O(n) 每组数据
- **空间复杂度**: O(1)

## 关键点
- 输入中第一个三角形是黑色三角形
- 判断一条边是否为多边形的边：两个顶点相邻（差1模n）或(0, n-1)这对
- 注意n=4时，黑色三角形可能有三条边都是多边形的边（退化情况）
- 不需要真正构建树或图，只需判断黑色三角形的三条边中有几条是多边形边

## 代码解析

```cpp
// 读取黑色三角形的三个顶点
int black_a, black_b, black_c;
cin >> black_a >> black_b >> black_c;

// 统计黑色三角形有多少条边是多边形的边
int edge_count = 0;

// 检查边 (black_a, black_b)
if ((black_a + 1) % n == black_b || (black_b + 1) % n == black_a ||
    (black_a == 0 && black_b == n-1) || (black_b == 0 && black_a == n-1)) {
    edge_count++;
}

// 类似检查另外两条边...

// 判断胜负：如果有至少一条边是多边形边，先手胜
if (edge_count > 0) {
    cout << "TAK\n";
} else {
    cout << "NIE\n";
}
```

核心逻辑很简单：检查黑色三角形的每条边是否是多边形的边。判断两个顶点是否相邻的条件：
- 差1模n：`(a+1)%n == b` 或 `(b+1)%n == a`
- 特殊情况：`(0, n-1)` 这对顶点也是相邻的
