# 题目 20 - Ms. Weasel eats chicken

## 题目大意
从0号小镇出发，依次经过1到n-1号小镇，最终到达n号小镇。初始体力S，每段路消耗w[i]体力，到达小镇i可以花P[i]买一只鸡恢复x体力。求最少花费，若无法到达输出-1。

## 解题思路

**核心问题**：体力不够时需要在之前经过的小镇中买鸡，但每个小镇只能买一次，且价格不同。

**关键观察**：
1. 我们可以在到达某个小镇后，回头买之前小镇的鸡吗？不行，只能买当前已到达的小镇。
2. 但我们可以"延迟决策"——当体力不够时，从之前经过的所有小镇中选最便宜的鸡买。

**贪心策略**：
- 维护一个"可购买"的小镇集合（按价格排序）
- 每次体力不足时，从最便宜的开始买
- 买完就删除（每个小镇只有一只鸡）

**为什么正确**：
- 如果未来需要买鸡，现在买最便宜的总是最优的
- 因为价格不会随时间变化，早买晚买价格一样
- 但早买可以避免体力为0饿死

## 算法分析
- **算法/数据结构**: 贪心 + 排序
- **时间复杂度**: O(n²)（每次排序，可优化为优先队列O(n log n)）
- **空间复杂度**: O(n)

## 关键点
- 每个小镇只能买一次，买完要删除
- 体力不够时要"立即"买鸡，不能等到下一段路
- 注意初始体力可能连第一段路都走不了
- 多组测试数据，读到EOF

## 代码解析

```cpp
// 维护一个可购买的小镇列表，按价格排序
vector<pair<ll, int>> cheap;

// 遍历每个路段
for (int i = 0; i < n; i++) {
    // 到达小镇i，加入候选
    cheap.push_back({P[i], i});
    sort(cheap.begin(), cheap.end()); // 保持最便宜在前
    
    // 体力不够走下一段路时，不断买最便宜的鸡
    while (cur_energy < w[i]) {
        if (cheap.empty()) { // 没鸡可买，无法完成
            possible = false;
            break;
        }
        // 买最便宜的鸡
        ll price = cheap[0].first;
        cur_energy += x;
        total_cost += price;
        cheap.erase(cheap.begin()); // 删除已买的鸡
    }
    
    if (!possible) break;
    cur_energy -= w[i]; // 消耗体力走这段路
}
```

**优化建议**：使用优先队列（最小堆）代替每次排序，可将时间复杂度降为O(n log n)。
