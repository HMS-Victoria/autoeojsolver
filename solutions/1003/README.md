# 题目 1003 - Boolean Expressions

## 题目大意
计算布尔表达式的值，表达式包含V(真)、F(假)以及运算符!（非）、&（与）、|（或），支持括号改变优先级，优先级从高到低为：! > & > |。

## 解题思路
这道题本质上是表达式求值问题，和计算算术表达式（如`3+5*2`）的思路完全一样，只是操作数变成了布尔值，运算符变成了逻辑运算符。

**为什么想到用栈？** 因为表达式求值的经典解法就是双栈法（操作数栈+运算符栈），利用栈的LIFO特性来处理运算符优先级和括号。

**核心思路：**
1. 遇到操作数（V/F）→ 压入操作数栈
2. 遇到左括号 → 压入运算符栈
3. 遇到右括号 → 弹出运算符并计算，直到遇到左括号
4. 遇到运算符 → 先处理栈中优先级不低于当前运算符的运算符，再压入当前运算符
5. 注意：!是单目运算符，只需要一个操作数，处理时要特殊对待

## 算法分析
- **算法/数据结构**: 栈（双栈法）
- **时间复杂度**: O(n)，n为表达式长度，每个字符最多入栈出栈一次
- **空间复杂度**: O(n)，栈的深度与表达式嵌套深度有关

## 关键点
- **单目运算符!的处理**：!只需要弹出一个操作数，而&和|需要弹出两个，这个区别容易忽略
- **优先级比较条件**：当前运算符优先级 ≤ 栈顶运算符优先级时才弹出计算（不是小于），因为同优先级需要从左到右计算
- **空格处理**：直接跳过即可，不影响逻辑
- **输入读取**：使用getline读取整行，直到EOF，注意跳过空行

## 代码解析

**1. 优先级函数**
```cpp
int precedence(char op) {
    if (op == '!') return 3;
    if (op == '&') return 2;
    if (op == '|') return 1;
    return 0;
}
```
定义运算符优先级，!最高，|最低，方便后续比较。

**2. 核心循环——遍历表达式**
```cpp
for (size_t i = 0; i < expr.length(); i++) {
    if (expr[i] == ' ') continue;  // 跳过空格
    
    if (expr[i] == 'V' || expr[i] == 'F') {
        values.push(charToBool(expr[i]));  // 操作数直接入栈
    }
    else if (expr[i] == '(') {
        ops.push(expr[i]);  // 左括号入栈
    }
    else if (expr[i] == ')') {
        // 弹出并计算直到遇到左括号
        while (!ops.empty() && ops.top() != '(') {
            // ... 计算逻辑
        }
        if (!ops.empty()) ops.pop(); // 弹出左括号
    }
    else if (expr[i] == '!' || expr[i] == '&' || expr[i] == '|') {
        // 处理优先级：栈顶优先级 >= 当前优先级时，先计算栈顶
        while (!ops.empty() && ops.top() != '(' && 
               precedence(ops.top()) >= precedence(expr[i])) {
            // ... 计算逻辑
        }
        ops.push(expr[i]);  // 当前运算符入栈
    }
}
```
这里的关键是**什么时候计算**：遇到右括号时强制计算到左括号；遇到运算符时，如果栈顶优先级不低于当前运算符，就先计算栈顶（保证高优先级先算）。

**3. 运算符计算逻辑**
```cpp
if (op == '!') {
    bool val = values.top(); values.pop();
    values.push(applyNot(val));  // 单目运算
} else {
    bool b = values.top(); values.pop();
    bool a = values.top(); values.pop();
    values.push(applyOp(a, b, op));  // 双目运算
}
```
注意单目和双目的区别：!只弹出一个操作数，&和|弹出两个（注意顺序，先弹出的是右操作数）。

**4. 最后处理剩余运算符**
```cpp
while (!ops.empty()) {
    // 同样的计算逻辑
}
```
表达式遍历完后，运算符栈中可能还有剩余运算符，需要全部计算完。
