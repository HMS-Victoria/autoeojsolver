# 题目 1001 - Problem A+B (Big Integer)

## 题目大意
计算两个不超过500位的大整数A和B的和。有多组测试数据，读到文件末尾结束。

## 解题思路
看到“不超过500位”这个条件，就知道不能用int或long long了——C++内置整数类型最多只能存几十位。500位已经远超它们的范围，必须用字符串模拟手算加法。

为什么想到用字符串模拟？因为小学学加法时，就是从个位开始逐位相加，满十进一。计算机模拟这个过程最自然：把两个数字字符串从末尾对齐，逐位相加，处理进位。

具体步骤：
1. 用字符串读入两个大数
2. 从两个字符串的最低位（末尾）开始遍历
3. 对应位数字相加，再加上上一位的进位
4. 当前位结果 = 和 % 10，新的进位 = 和 / 10
5. 处理完所有位后，如果还有进位，要补上
6. 最后把结果反转（因为我们是倒着存的）

## 算法分析
- **算法/数据结构**: 模拟（大数加法）
- **时间复杂度**: O(max(lenA, lenB))，需要遍历两个数字的每一位
- **空间复杂度**: O(max(lenA, lenB))，存储结果字符串

## 关键点
- 字符串转数字时记得减'0'，数字转字符时加'0'
- 两个数字长度可能不同，短的数高位视为0
- 最后一位相加后可能有进位，别忘了处理
- 结果要反转，因为是从低位往高位存的
- 多组输入，用while(cin >> a >> b)读到EOF

## 代码解析
```cpp
string addBigNumbers(string a, string b) {
    string result = "";
    int carry = 0;
    int i = a.length() - 1, j = b.length() - 1;
```
定义进位变量carry，从两个字符串的末尾开始遍历。

```cpp
    while (i >= 0 || j >= 0 || carry) {
        int sum = carry;
        if (i >= 0) sum += a[i--] - '0';
        if (j >= 0) sum += b[j--] - '0';
        carry = sum / 10;
        result += (sum % 10) + '0';
    }
```
循环条件包含`carry`是为了处理最后可能多出的进位。每次把当前位的数字和进位加起来，取个位存入结果，十位作为新进位。

```cpp
    reverse(result.begin(), result.end());
    return result;
}
```
因为是从低位往高位存的，所以最后要反转得到正确顺序。

```cpp
int main() {
    string a, b;
    while (cin >> a >> b) {
        cout << addBigNumbers(a, b) << endl;
    }
    return 0;
}
```
多组输入，读到文件尾结束。注意输入样例是三组数据，所以要用循环处理。
