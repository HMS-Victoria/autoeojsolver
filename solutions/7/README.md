# 题目 7 - Balls

## 题目大意
给定 B 个相同的球和一座 M 层的楼，球在某个临界楼层 F 以下掉落不会碎，在 F 及以上会碎。求在最坏情况下，用最优策略需要多少次掉落才能确定 F。

## 解题思路
这是一个经典的“鸡蛋掉落”问题（Two Glass Balls 变种）。核心是动态规划。

1.  **状态定义**：设 `dp[i][j]` 表示有 `i` 个球和 `j` 层楼时，最坏情况下所需的最小掉落次数。
2.  **边界条件**：
    -   如果只有 1 个球（`i == 1`），只能从 1 楼逐层往上试，最坏情况需要试 `j` 次（即 `dp[1][j] = j`）。
    -   如果只有 1 层楼（`j == 1`），无论有多少球，都只需要 1 次掉落（`dp[i][1] = 1`）。
    -   如果楼层为 0，不需要掉落（`dp[i][0] = 0`）。
3.  **状态转移**：对于 `dp[i][j]`，我们选择从第 `k` 层（`1 <= k <= j`）扔下第一个球。此时有两种可能：
    -   **球碎了**：说明临界楼层在 `k` 层以下，问题变为 `dp[i-1][k-1]`（球少一个，楼层变为 `k-1` 层）。
    -   **球没碎**：说明临界楼层在 `k` 层以上，问题变为 `dp[i][j-k]`（球数不变，楼层变为 `j-k` 层）。
    -   因为我们要考虑**最坏情况**，所以取这两种情况中的最大值：`1 + max(dp[i-1][k-1], dp[i][j-k])`（加 1 是因为当前这次掉落）。
    -   我们想要**最小化**这个最坏情况，所以遍历所有可能的 `k`，取最小值：`dp[i][j] = min(1 + max(dp[i-1][k-1], dp[i][j-k]))`。

## 算法分析
- **算法/数据结构**: 动态规划 (DP)
- **时间复杂度**: O(B * M^2) —— 三层循环：球数 (B)、楼层数 (M)、尝试的楼层 k (M)。
- **空间复杂度**: O(B * M) —— 用于存储 DP 表。

## 关键点
-   **理解最坏情况**：在状态转移中，我们取 `max` 是因为我们无法控制球碎或不碎，必须考虑对策略最不利的情况。
-   **理解最小化**：我们取 `min` 是因为我们可以选择从哪一层开始扔，从而选择最优的起始楼层。
-   **边界初始化**：`dp[1][j] = j` 和 `dp[i][1] = 1` 是推导的基础，必须正确初始化。
-   **数据范围**：题目中 B <= 50, M <= 1000，O(B*M^2) 的复杂度在 1000 组数据下可能较高，但题目 P <= 1000，且 M 最大 1000，实际运行时间在可接受范围内。对于更大的数据，可以考虑使用二分优化或数学方法。
