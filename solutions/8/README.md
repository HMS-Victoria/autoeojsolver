# 题目 8 - 愚人节快乐

## 题目大意
给定一个数字n，输出斐波那契数列（从1,1开始）拼接成的一个长字符串的前n个字符。

## 解题思路
这道题的核心是理解“拼接”的含义。不是输出第n个斐波那契数，而是把斐波那契数列的每个数当作字符串拼在一起，然后取前n位。

为什么这么想？观察样例：
- n=3 → 输出112（斐波那契：1,1,2 → 拼接成"112"）
- n=6 → 输出112358（1,1,2,3,5,8 → "112358"）
- n=7 → 输出1123581（下一个数是13，拼接后"11235813"，取前7位）

关键是要意识到：斐波那契数会越来越大，位数也会增加，所以不能简单地用数组存数字，而要用字符串动态拼接。

## 算法分析
- **算法/数据结构**: 模拟 + 字符串拼接
- **时间复杂度**: O(n) — 每次生成一个斐波那契数并拼接，直到字符串长度达到n
- **空间复杂度**: O(n) — 存储拼接结果字符串

## 关键点
- 斐波那契数列从1,1开始，不是从0,1开始
- 拼接的是数字的字符串形式，不是数字本身
- 当结果长度超过n时，用substr取前n个字符
- 注意n=1的特殊情况，直接输出"1"
- 斐波那契数可能很大，要用long long（但题目n≤100，其实不会溢出）

## 代码解析
```cpp
string result = "11";  // 初始拼接前两个数
long long a = 1, b = 1;  // 当前的两个斐波那契数

while (result.length() < n) {
    long long c = a + b;  // 计算下一个数
    string numStr = to_string(c);  // 转成字符串
    result += numStr;  // 拼接到结果后面
    a = b;
    b = c;
}

cout << result.substr(0, n) << endl;  // 取前n个字符输出
```

核心逻辑就是不断生成下一个斐波那契数，转成字符串拼接到结果后面，直到长度足够。最后用substr截取前n位。注意n=1时直接输出"1"避免循环逻辑问题。
