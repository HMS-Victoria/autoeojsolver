# 题目 3 - 玩具谜题

## 题目大意
有n个玩具小人围成一圈，每个有朝向（朝内/朝外）和职业。从第1个小人开始，依次执行m条指令（左数/右数第s个），输出最终到达的小人的职业。

## 解题思路

**核心难点**：左右方向与朝向的关系。

关键发现：
1. 朝向决定了“左”和“右”的实际方向
2. 朝内：左=顺时针，右=逆时针
3. 朝外：左=逆时针，右=顺时针

**推导过程**：
- 把顺时针记为+1，逆时针记为-1
- 朝内时：左数(+1)，右数(-1)
- 朝外时：左数(-1)，右数(+1)
- 观察发现：当朝向和指令方向相同时（都是0或都是1），走顺时针；不同时走逆时针

**为什么这样想**：
因为题目本质是模拟，关键在于正确映射“左右”到实际移动方向。用正负号表示方向可以统一处理。

## 算法分析
- **算法/数据结构**: 模拟
- **时间复杂度**: O(n + m)
- **空间复杂度**: O(n)

## 关键点
- 方向映射要理清：朝内(0)时左数=顺时针(+1)，朝外(1)时左数=逆时针(-1)
- 取模处理循环：`(current + move * s) % n`，注意负数要加n
- 用结构体存储朝向和职业，方便读取
- 注意输入顺序：先读n,m，再读n个小人信息，最后读m条指令

## 代码解析

```cpp
struct Toy {
    int direction; // 0: 朝内, 1: 朝外
    string job;
};
```
用结构体存储每个小人的信息，清晰明了。

```cpp
int move;
if (toys[current].direction == 0) { // 朝内
    if (a == 0) move = 1;      // 左数 = 顺时针
    else move = -1;            // 右数 = 逆时针
} else { // 朝外
    if (a == 0) move = -1;     // 左数 = 逆时针
    else move = 1;             // 右数 = 顺时针
}
```
核心逻辑：根据当前小人的朝向和指令方向，确定实际移动方向（+1顺时针，-1逆时针）。

```cpp
current = (current + move * s) % n;
if (current < 0) current += n;
```
计算新位置，注意C++取模可能得到负数，需要处理。
