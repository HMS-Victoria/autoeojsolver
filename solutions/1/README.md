# 题目 1 - A+B Problem

## 题目大意
给定两个整数 a 和 b，输出它们的和。

## 解题思路
这是最简单的入门题，直接读取两个整数并相加输出即可。需要注意输入可能包含多组测试数据，因此需要用循环持续读取直到文件结束。

## 算法分析
- **算法/数据结构**: 无特殊算法
- **时间复杂度**: O(1) 每组数据
- **空间复杂度**: O(1)

## 关键点
- 使用 `long long` 而非 `int`，防止两个大整数相加时溢出
- 使用 `while (cin >> a >> b)` 处理多组输入，直到文件结束
- 注意输出格式，每组结果占一行

## 代码解析
```cpp
long long a, b;  // 用 long long 保证能处理大数
while (cin >> a >> b) {  // 持续读取，直到没有更多输入
    cout << a + b << endl;  // 直接输出和，换行
}
```
