# 题目 18 - Pokémon and candies

## 题目大意
你有 n 个金币，可以购买无色糖果。通过两种烹饪方式消耗无色糖果并返还金币：热烹饪消耗 a 颗糖果，进化一级并返还 b 金币；冷烹饪消耗 c 颗糖果，进化一级并返还 d 金币。求最多能进化多少级。

## 解题思路
这道题的核心是**线性规划**。设热烹饪次数为 x，冷烹饪次数为 y，则：
- 总消耗糖果：a*x + c*y
- 总返还金币：b*x + d*y
- 初始金币：n
- 约束条件：a*x + c*y ≤ n + b*x + d*y  →  (a-b)*x + (c-d)*y ≤ n
- 目标：最大化 x + y

由于只有两个变量，我们可以枚举其中一个（比如 x），然后根据约束条件直接算出另一个的最大可能值 y。

**关键点**：如果某种烹饪的消耗小于返还（即 a ≤ b 或 c ≤ d），那么这种烹饪可以无限进行，导致无限进化。题目数据应该保证不会出现这种情况，但代码中需要做保护。

**为什么枚举 x 而不是 y？** 因为对称性，枚举哪个都一样。我们选择枚举 x，然后根据不等式解出 y 的最大值。

## 算法分析
- **算法/数据结构**: 数学推导 + 枚举
- **时间复杂度**: O(枚举范围)，通常限制在 2e6 以内
- **空间复杂度**: O(1)

## 关键点
- 约束条件要正确推导：花费 ≤ 初始金币 + 返还
- 注意处理 a ≤ b 或 c ≤ d 的情况（无限进化）
- 枚举范围要合理：当 a > b 时，x 最大为 n/(a-b)；当 a ≤ b 时，需要设一个上限防止超时
- 使用 long long 防止溢出
