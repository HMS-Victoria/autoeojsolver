# 题目 21 - Mr. Sloth and his party

## 题目大意
有n位叔叔和n位姐姐，初始位置给定。每支舞曲中，每位叔叔必须与一位距离不超过r的姐姐配对跳舞，跳完后两人交换位置，且同一位置对只能跳一次。问最多能跳多少支舞曲。

## 解题思路

**关键观察**：每跳完一支舞，叔叔和姐姐的位置会交换，这意味着下一支舞的配对关系会完全改变。但问题可以转化为：在每一轮中，我们能否找到一个完美匹配（所有n对都能配对）？如果能，就继续下一轮。

**为什么用二分图匹配**：
- 叔叔和姐姐是两类节点，只能异性配对 → 天然二分图
- 距离限制r决定了两点之间是否有边
- 每轮需要所有n对都配对成功 → 完美匹配问题

**为什么可以重复匹配**：
- 虽然同一位置对只能跳一次，但每次交换位置后，叔叔和姐姐的位置都变了
- 所以下一轮的图是全新的，之前的匹配不影响新图

**算法流程**：
1. 根据当前位置和距离r构建二分图
2. 用匈牙利算法求最大匹配
3. 如果匹配数 < n，结束
4. 否则，根据匹配结果交换叔叔和姐姐的位置
5. 重复步骤1-4

## 算法分析
- **算法/数据结构**: 二分图最大匹配（匈牙利算法）
- **时间复杂度**: O(k * n³)，其中k是舞曲数，n是人数（最坏情况n=100，k可能较大但有限）
- **空间复杂度**: O(n²)

## 关键点
- **浮点数精度**：距离比较时加上1e-9的小误差，避免sqrt导致的精度问题
- **位置交换逻辑**：匹配后，叔叔去姐姐的位置，姐姐去叔叔的位置，注意索引对应关系
- **循环终止条件**：一旦某轮无法完美匹配，立即停止
- **多组数据**：输入直到EOF，每组独立处理

// 匈牙利算法核心：寻找增广路
bool dfs(int u) {
    for (int v : g[u]) {  // 遍历所有可能的姐姐
        if (!vis[v]) {
            vis[v] = true;
            // 如果姐姐未匹配，或能通过姐姐的当前匹配找到新的增广路
            if (match[v] == -1 || dfs(match[v])) {
                match[v] = u;  // 更新匹配
                return true;
            }
        }
    }
    return false;
}

// 主循环：不断尝试跳舞
