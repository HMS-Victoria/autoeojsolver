# 题目 30 - 数字字符个数

## 题目大意
实现一个函数，统计给定字符串中数字字符（'0'-'9'）的个数。

## 解题思路
这道题是字符串遍历的基础题，核心思路非常直接：
1. 遍历字符串中的每个字符
2. 判断字符是否在'0'到'9'的ASCII码范围内
3. 如果是则计数加1

为什么这么想？因为题目明确要求统计数字字符，而数字字符在ASCII码中是连续的一段，所以用范围判断即可。不需要用isdigit()函数，自己写判断更灵活。

## 算法分析
- **算法/数据结构**: 字符串遍历
- **时间复杂度**: O(n)，n为字符串长度
- **空间复杂度**: O(1)，只用了常数个变量

## 关键点
- 字符串以'\0'结尾，这是遍历的终止条件
- 字符比较要用单引号，如 `'0'` 而不是 `0`
- 指针移动要记得，否则会死循环
- 计数器要初始化为0

## 代码解析
```c
int count = 0;  // 初始化计数器
while (*s != '\0')  // 遍历到字符串末尾
{
    if (*s >= '0' && *s <= '9')  // 判断是否为数字字符
    {
        count++;  // 计数
    }
    s++;  // 移动指针到下一个字符
}
return count;  // 返回结果
```

核心逻辑就是循环+判断，没有复杂的技巧。注意指针的移动和终止条件的判断即可。
