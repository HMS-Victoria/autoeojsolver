# 题目 10 - Bob and a Binary tree

## 题目大意
给定一个无限完全二叉树，节点按层序遍历编号，每个节点是一个有理数。根节点为1/1，左儿子为p/(p+q)，右儿子为(p+q)/q。给定n，求第n个节点的有理数。

## 解题思路

**关键洞察**：这棵树实际上是著名的Calkin-Wilf树，它有一个非常重要的性质——第n个有理数可以通过n的二进制表示直接得到。

**为什么想到二进制？**
1. 观察遍历顺序：层序遍历，每个节点编号n对应一个唯一的二进制表示
2. 从根到节点的路径可以用二进制表示：0表示向左，1表示向右
3. 但注意：根节点编号为1，二进制为1，去掉最高位后为空路径

**推导过程**：
1. 将n写成二进制，例如n=5 → 101
2. 去掉最高位的1，得到"01"
3. 从左到右扫描：0表示向左，1表示向右
4. 从(1/1)开始，按照路径移动：
   - 遇到0（向左）：p不变，q = p+q
   - 遇到1（向右）：p = p+q，q不变

**为什么去掉最高位？**
因为根节点本身不需要移动，最高位的1代表根节点本身，后续的位才表示移动方向。

## 算法分析
- **算法/数据结构**: 数学推导 + 二进制位运算
- **时间复杂度**: O(log n) — 需要遍历n的二进制位数
- **空间复杂度**: O(1) — 只使用常数空间

## 关键点
- **二进制处理技巧**：先找到最高位，然后从次高位开始遍历
- **long long类型**：n最大可达2^31左右，需要用long long存储
- **路径方向**：0向左（分母变化），1向右（分子变化），容易记反
- **初始值**：从(1/1)开始，不是从空开始

## 代码解析

```cpp
void findFraction(long long n, long long &p, long long &q) {
    p = 1, q = 1;  // 从根节点开始
    
    // 找到最高位：不断左移直到超过n，再右移一位
    long long highest = 1;
    while (highest <= n) {
        highest <<= 1;
    }
    highest >>= 1;  // 此时highest是n的最高位
    
    // 从次高位开始遍历
    long long mask = highest >> 1;
    while (mask > 0) {
        if (n & mask) {
            // 当前位是1 → 向右走：分子变成分子+分母
            p = p + q;
        } else {
            // 当前位是0 → 向左走：分母变成分子+分母
            q = p + q;
        }
        mask >>= 1;  // 处理下一位
    }
}
```

**核心逻辑**：
- `highest`找到最高位，例如n=5(101)时，highest=4(100)
- `mask`从次高位开始，即highest>>1=2(010)
- 每次判断当前位是0还是1，更新p或q
- 注意：更新p或q时，另一个值保持不变，这正是Calkin-Wilf树的性质
