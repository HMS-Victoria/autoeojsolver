# 题目 13 - Eudoku and Sudoku

## 题目大意
这是一个6×6的变种数独（欧独），除了行、列不能重复外，还要保证3×2的块内不重复。有些格子需要填两个数字（用斜杠分隔），且要求左边数字小于右边数字。输入给出部分已知数字，需要填满整个棋盘。

## 解题思路

**为什么想到DFS回溯？**
- 这是一个典型的约束满足问题，类似标准数独
- 6×6的规模不大，暴力搜索可行
- 需要处理“两个数字”的特殊格子，DFS可以灵活处理不同情况

**核心思路：**
1. 把每个格子抽象成三种状态：单数字、双数字（两个都未填）、双数字（一个已填一个未填）
2. 用三个布尔数组记录行、列、块的数字使用情况，快速判断合法性
3. 从左到右、从上到下依次填格子，遇到双数字格子时，要保证v1 < v2

**为什么这样设计状态？**
- 输入中有些双数字格子已经填了一个数字（如“-/5”），需要特殊处理
- 用val1和val2分别表示左右数字，0表示未填，这样统一处理所有情况

## 算法分析
- **算法/数据结构**: DFS回溯 + 剪枝（约束检查）
- **时间复杂度**: O(9^(6×6)) 最坏情况，但实际由于约束条件，搜索空间小很多
- **空间复杂度**: O(1)（三个6×10的布尔数组 + 6×6的棋盘）

## 关键点
- **双数字格子的处理**：必须保证v1 < v2，且两个数字不能相同
- **已填数字的标记**：读入时就要把已知数字标记到行、列、块的使用数组中
- **DFS顺序**：从左到右、从上到下，遇到已填的格子直接跳过
- **回溯时恢复状态**：不仅要恢复格子的值，还要恢复三个使用数组

## 代码解析

**数据结构设计：**
```cpp
struct Cell {
    int val1;  // 左边数字，0表示未填
    int val2;  // 右边数字，0表示没有或未填
    bool hasTwo; // 标记是否为双数字格子
};
```
这样设计可以统一处理单数字和双数字格子，val2=0且hasTwo=false表示单数字格子。

**DFS核心逻辑：**
```cpp
bool dfs(int r, int c) {
    if (r == 6) return true; // 填完所有格子
    
    // 计算下一个格子的坐标
    int nr = (c == 5) ? r + 1 : r;
    int nc = (c == 5) ? 0 : c + 1;
    
    Cell& cell = board[r][c];
    
    // 情况1：单数字且已填，直接跳过
    if (cell.val1 != 0 && !cell.hasTwo) return dfs(nr, nc);
    
    // 情况2：双数字格子，分三种子情况处理
    if (cell.hasTwo) {
        // 两个都未填：枚举v1，然后枚举v2 > v1
        // 第一个未填第二个已填：枚举v1 < cell.val2
        // 第一个已填第二个未填：枚举v2 > cell.val1
    }
    
    // 情况3：单数字未填，枚举1-9
}
```

**为什么分三种子情况？**
因为输入可能已经给了双数字格子中的一个数字，我们需要在已有约束下填另一个。这样分情况处理让代码更清晰，也避免了不必要的枚举。

**回溯的完整性：**
每次尝试填数字时，都要同时更新三个使用数组；回溯时也要同时恢复。这是DFS求解约束满足问题的标准做法，漏掉任何一个都会导致错误。
