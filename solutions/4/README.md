# 题目 4 - Nth Largest Value

## 题目大意
给定多个数据集，每个数据集包含一个编号和10个整数，要求输出每个数据集中第3大的数。

## 解题思路
题目要求“第3大的数”，也就是降序排列后位于第3位的数。因为数据量很小（每组只有10个数），直接排序取第3个即可。

- 读入数据集个数P
- 对每个数据集：
  - 读入编号和10个整数
  - 将这10个数降序排序
  - 取排序后索引为2（0-based）的数作为第3大的数
  - 按格式输出

## 算法分析
- **算法/数据结构**: 排序（直接调用 sort）
- **时间复杂度**: O(P * 10 log 10) ≈ O(P)，因为10是常数
- **空间复杂度**: O(1)（只存10个数）

## 关键点
- 注意“第3大”不是“第3小”，要降序排序
- 数组大小固定为10，排序开销很小，不用想复杂算法
- 每组数据输出格式：编号 + 空格 + 结果
