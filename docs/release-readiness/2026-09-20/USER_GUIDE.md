# EOJ 解题助手 4.0.1（Windows 10/11 x64）

本包已生成后仍须进行干净机器验收；请以随附发布记录的实际结果为准。

1. 完整解压 ZIP 到纯英文的可写目录（例如 D:/EOJSolver，可含空格；当前工具链不支持中文路径），不要在压缩包中直接运行，也不要单独移动 EXE。
2. 双击 EOJSolver.exe。首次设置会说明账号、模型服务和本地自检步骤。
3. 填写 EOJ 账号和密码，选择模型供应商，填写 Key、接入点与模型名。
4. “首次设置 / 自检”完全离线，编译并运行两个合成 C++17 样例；“测试 API”会连接您填写的服务并可能产生费用。“测试登录”会连接 EOJ。
5. 默认不提交。先保持“本地编译测试”开启；只有明确勾选提交且本地样例通过后才会向站点提交。缺少编译器、跳过测试、无样例或测试失败均不能作为验证成功。

内含 Python/Tk、程序依赖和完整私有 MSYS2 UCRT GCC 16.2.0 / MinGW-w64 14 工具链，不需要另装 Python/g++，不修改系统 PATH。不能把“依赖已打包”当作已经通过新电脑验收。
配置与题解在 %LOCALAPPDATA%\EOJSolver；测试人员可用 EOJ_DATA_DIR 指定独立目录。选中“记住配置”会明文保存账号凭据与 Key，请勿分享此目录。发行包不附带作者题解、缓存、登录状态或个人配置。
更新：解压新版本到新的文件夹；用户数据独立保存。卸载：删除解压目录即可；请自行备份后再决定是否删除用户数据。

离线诊断（交接/验收用）：
EOJSolver.exe --self-test C:\eoj-test\report.json --gui-smoke
此命令使用合成模型/站点，不进行真实登录或提交。report.json 的 ok=true 表示本地离线检查通过，不代表真实服务或人工界面验收。

已知限制：程序解压目录和系统临时目录须为纯英文路径；中文路径实测链接失败。未签名；仅提供 x64 包；真实站点登录、验证码交互、模型服务与提交由用户另行人工验收；自动生成的 C++ 会在当前用户权限下运行，程序没有隔离执行不可信代码的沙箱。
许可资料见 licenses 和 toolchain\ucrt64\share\licenses；工具链对应源码、补丁和构建配方另附于 EOJSolver-4.0.1-toolchain-sources.zip。
